**My First Slack Bot**

This project was made for Hack Club's *Stardance* YSWS program.

**Prereqs**

Node.js and Git. 

**How to run it**
Clone this repo, the run `npm install` to install dependencies. Then just run `node index.js` to start the actual bot.

**Other Info**

I am not going to go into detail on how to setup the ENV file, or how to setup the actual slack application. For that go to the [guide](https://stardance.hackclub.com/missions/slack-bot/guide) that is on stardance's website.
